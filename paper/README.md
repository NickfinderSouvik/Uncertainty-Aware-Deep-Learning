# Research Paper

This directory contains the academic paper associated with:

"When Should AI Say I Don't Know?"

The paper investigates:
- Neural network uncertainty estimation
- Temperature scaling
- Monte Carlo Dropout
- Deep ensembles
- Calibration under Gaussian image corruption
- Error detection and selective prediction

The manuscript includes methodology, experimental results,
discussion, limitations, conclusion, and IEEE-style references.
